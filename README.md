# CareerBot - Automated Job Application Bot

<p id="intro">CareerBot is an experimental automated bot designed to apply for jobs that match your skills and preferences. Users can set specific criteria for job applications, and if those criteria are met, CareerBot will automatically submit applications on your behalf. Customize the number of applications per day, and let CareerBot handle the rest.</p>

## Features and Benefits ✨

- Automated job application process
- Customizable criteria to match your skills and preferences
- Daily application quota that can be set by the user
- Hands-free job search and application
- Continuous job application process without manual intervention
- Ideal for broadening job search reach and saving time

## Use Cases ✅

- Applying to jobs that meet specific skill requirements automatically
- Setting a daily limit for job applications to manage search efforts
- Experimenting with automated job search strategies
- Broadening job search without spending time on manual applications
- Ensuring that no relevant job opportunity is missed

## Installation - Step-by-Step Guide 🪜

- **Step 1:** Download latest release and extract in your system.
- **Step 2:** Now open the extracted folder
- **Step 3:** Run main program

```bash
python main.py
```

- **Step 4:** Now you need to press enter to install careerbot

```bash
Let start with installation
press enter to continue

```

- **Step 5:** Now desktop shortcut would be created. from now on you can set preference and log in using that shorcut link to app.

```bash
What to do?
  1.Login
  2.Set job filter
  3.Schedule CareerBot
  4.Delete CareerBot schedule
  5.Uninstall
  6.Exit
  ##########################################
  Input:
```
